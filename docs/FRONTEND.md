## 2026-10-24 — Regole di sicurezza del database (urgente)
- Ramo / Pull Request: `claude/project-thread-w2nwxw` / https://github.com/Jarvis-00-ip/Drivy.it-webapp/pull/3 (collegata: https://github.com/Jarvis-00-ip/app-scuola-guida/pull/1)

Aggiunte le regole `firestore.rules`: ogni scuola vede solo i suoi dati, allievi e istruttori vedono solo quello che spetta al loro ruolo, tutto il resto è vietato. I codici invito ora usano il codice come ID del documento, così nessuno può elencare quelli delle altre scuole. Il calendario degli istruttori usa lo `school_id` della loro scuola.
